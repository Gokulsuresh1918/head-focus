Head Focus

Look at a monitor → keyboard focus follows. Runs on your PC only (webcam + Windows).

Download

This is not a web app — you install it once on Windows and run it locally.

Latest release (ZIP) Source ZIP (main branch)

Setup (about 5 minutes)

  1. Install Python 3.10+ and check Add python.exe to PATH.
  2. Unzip the download to a folder (e.g. C:\Apps\head-focus).
  3. Double-click install_windows.bat (once).
  4. Double-click Launch Head Focus.bat → Test camera → Start.
  5. Allow Camera for python.exe / pythonw.exe when Windows asks.

Privacy: Video stays on your machine. The app only downloads Google’s public face model (~10 MB) on first run.
