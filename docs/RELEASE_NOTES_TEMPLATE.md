## Head Focus 1.0.0

Windows app: move **keyboard focus** to the monitor you look at (webcam head tracking).

### Download

1. Download **`head-focus-1.0.0.zip`** below.
2. Unzip, run **`install_windows.bat`** once, then **`Launch Head Focus.bat`**.
3. Requires **Python 3.10+** and camera permission for `python.exe` / `pythonw.exe`.

### Requirements

- Windows 10/11, webcam, Python 3.10+
- Multiple monitors recommended

### Hotkeys

- **Ctrl+Alt+H** — pause / resume  
- **Ctrl+Alt+C** — recenter  
- **Ctrl+Alt+S** — settings
